# مدار تك

موقع عربي ثابت مع لوحة تحكم للمحتوى، دون حزم أو خطوات بناء.

## التشغيل

من مجلد المستودع:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

افتح `index.html` للموقع و`dashboard/admin.html` للوحة التحكم عبر الخادم نفسه (بنفس المضيف والمنفذ).

## لوحة التحكم

- إضافة وتعديل وحذف البرامج والخدمات، وإظهارها أو إخفاؤها.
- البحث والتصفية حسب حالة الظهور.
- تعديل البريد الإلكتروني والعنوان وإنستغرام ورقم واتساب.
- تصدير المحتوى إلى JSON واستيراد نسخة محفوظة بعد التأكيد.

تُحفظ البيانات في `localStorage` تحت المفتاح `madar-content-v1`. تظهر التغييرات في المتصفح والأصل نفسيهما فقط. حذف بيانات المتصفح يمحو التعديلات؛ استخدم التصدير لحفظ نسخة. لا توجد حسابات أو حماية تسجيل دخول أو قاعدة بيانات أو نشر مركزي. لا تضع بيانات سرية في اللوحة. التشغيل الإنتاجي مع إدارة مشتركة يتطلب خادمًا ومصادقة وتخزينًا مركزيًا.

رقم واتساب فارغ افتراضيًا؛ لتفعيل نموذج التواصل أدخل الرقم مع رمز الدولة دون `+` أو مسافات في الإعدادات. النموذج يفتح واتساب لتأكيد الإرسال من المستخدم ولا يخزن رسائل الزوار أو يعرض إحصاءات زيارات.

الموقع يستخدم Bootstrap من `cdn.jsdelivr.net` وخط Cairo من Google Fonts، مع خط Dahab محلي. لوحة التحكم تعمل دون تبعيات خارجية.

## فحص JavaScript

```sh
node --check main.js
node --check site-data.js
node --check site-content.js
node --check dashboard/admin.js
```

للتحقق الوظيفي: أضف برنامجًا في اللوحة ثم أعد تحميل الموقع من الأصل نفسه، وتحقق من ظهوره، ثم إخفائه وتعديله وحذفه. اختبر تصدير البيانات واستيرادها وتحديث إعدادات التواصل.
